# Uncertainty at the Threshold: Sampling Error in Geospatial Policy Tools

This repository contains the code used to reproduce the analyses presented in the manuscript **“Uncertainty at the Threshold: Sampling Error in Geospatial Policy Tools.”**

The repository includes the analytical workflow for uncertainty propagation, threshold analysis, designation simulations, and spatial analysis.

A permanent archived version of this repository will be created upon publication.

---

## Repository Structure

- `1_code/main.ipynb` – main analytical workflow and documentation
- `1_code/functions/` – functions used for data processing, index construction, uncertainty analysis, and spatial analysis
- `0_data/input/demo/` – synthetic demonstration data
- `0_data/output/demo/` – outputs generated by the demonstration workflow
- `2_plots/` – generated figures
- `LICENSE` – GPL v3

---

## Demonstration Data

The repository includes a synthetic demonstration dataset in `0_data/input/demo/`.

The demonstration data allow the analytical workflow to be run without downloading and processing the complete national datasets. 

The demonstration data are synthetic and do not represent actual census tracts or empirical study results. A synthetic regular-grid geometry dataset is included for the spatial analysis and does not represent real U.S. geography.

Outputs generated from the demonstration are written to `0_data/output/demo/`.

## Demo Runtime

The complete demonstration workflow took approximately **2 minutes** on the tested macOS system using the recommended Python 3.12 conda-forge environment.

Runtime was measured by executing `1_code/main.ipynb` from start to finish using:

```bash
jupyter nbconvert \
  --to notebook \
  --execute 1_code/main.ipynb \
  --output /tmp/quise_demo_runtime.ipynb
```

## Running the Demonstration

Open `1_code/main.ipynb` in Jupyter and run the notebook sequentially from the first cell to the last. Later cells use outputs generated by earlier cells.

The demonstration workflow:

1. constructs demographic indicators and denominators;
2. constructs the point-estimate vulnerability index;
3. constructs 80 replicate index realizations;
4. propagates sampling uncertainty through the index;
5. evaluates classification uncertainty around policy-relevant thresholds;
6. evaluates alternative designation scenarios;
7. performs the spatial distance analysis using the synthetic regular grid; and
8. generates the corresponding figures.

The demonstration reproduces the analytical workflow but not the national numerical results reported in the manuscript.

Generated outputs are written to `0_data/output/demo/`. Figures are written to `2_plots/`.

## Expected Demonstration Outputs

The demonstration generates the point-estimate index, 80 replicate index realizations, classification-stability results, spatial distance results, and corresponding figures.

Analytical outputs are written to `0_data/output/demo/` and figures to `2_plots/`.

All demonstration results are based on synthetic data and do not reproduce the empirical values reported in the manuscript.

## Complete Manuscript Analysis

The complete manuscript analysis follows the same general workflow using the full national datasets.

The principal analytical stages are:

1. preparation of ACS Variance Replicate Table inputs;
2. construction of the modified social vulnerability index;
3. generation of 80 replicate index realizations;
4. propagation and quantification of sampling uncertainty;
5. threshold-based classification analysis;
6. uncertainty-aware designation simulations; and
7. spatial analysis of classification uncertainty.

The national spatial analysis is substantially more computationally demanding than the synthetic demonstration.

## Data Sources

The primary demographic inputs are publicly available data from the U.S. Census Bureau.

### American Community Survey Variance Replicate Tables

ACS Variance Replicate Tables (VRTs) are available from:

https://www.census.gov/programs-surveys/acs/data/variance-tables.html

The VRTs provide the 80 variance replicate estimates used to propagate ACS sampling uncertainty through the composite index.

The complete national source datasets are not redistributed in this repository. The synthetic data in `0_data/input/demo/` are provided to allow execution of the analytical workflow.

---

## Using Other Data

The workflow can be run with ACS Variance Replicate Tables that follow the same structure as the demonstration inputs in `0_data/input/demo/`.

The required tables must contain the estimate and 80 variance replicate columns used by the analytical functions. The bundled demonstration files provide examples of the expected structure.

The input paths can be changed in `1_code/main.ipynb` before running the workflow.
